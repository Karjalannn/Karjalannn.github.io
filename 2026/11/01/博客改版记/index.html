今天花了大半天，把这个博客里里外外翻新了一遍。换主题、换评论、加搜索，顺手删掉了几个早就该删的东西。记录一下。

换了个主题

原来是 pln，现在换成了 SoSimple。

选它的理由很简单：极简、没有花里胡哨的动画、纯 HTML 也能正常阅读。整个前端的 JS + CSS 压缩完只有二十几 KB，打开速度确实快了一截。

代价是它用 TypeScript + JSX 写模板，要编译才能用，改起来比传统的 ejs 主题麻烦一些。中间踩了两个坑：

  • 主题的源码目录和 Hexo 的模板目录打架，标签页和搜索页会直接把 TSX 源码当页面输出；
  • 系统 PATH 里有一条带引号的坏路径，命令行找不到 pnpm，构建直接挂掉。

都在本地改好后写进文档了，这里就不展开了。

评论换成了 utterances

原来的 Gitalk 早就不能用了——它依赖的那个 OAuth 代理已经挂掉，点了也没反应。

现在用 utterances：评论直接存进这个仓库的 GitHub Issues 里，不需要服务器、不需要数据库，登录 GitHub 账号就能留言。每篇文章第一次有人评论时，会自动开一个 Issue，我在 GitHub 上就能回复和管理。

删掉的东西

  • 访问量统计。原来页面底部有个「本站总访问量」，是接的不蒜子。说实话这个数字对我也没什么意义，还要多加载一个脚本，索性整个删掉了。
  • 旧的评论代码。Gitalk 那套连同配置一起清理干净了。

加上的东西

  • 站内搜索：导航栏的「搜索」，可以模糊匹配标题和正文，文章多了以后会很有用。
  • 文章目录：这篇没有小标题就看不到，像《记高考》那种长文，顶部会自动生成目录。
  • 标签页：按标签翻文章，现在有「生活」「投资」「高考」几个。
  • 日夜模式：右上角的「日间/夜间」，选择会记在浏览器里。

顺便记两笔

博客的源码目前只在这台电脑上，GitHub 仓库里放的是构建出来的静态文件。等哪天有空，得把 source/ 备份到私有仓库，不然硬盘一坏，文章就全没了。
